# Auto Crop for Photographed Pages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let users crop photographed pages with perspective correction (manual editor, per page), with an Auto Crop button that detects page edges on image pages, and make gallery and camera uploads from iPhone and Android behave correctly (HEIC, EXIF rotation, large photos).

**Architecture:** Pure, unit-tested modules (`crop-geometry.js`, `image-normalize.js`, `crop-state.js`, `page-detect.js`) hold all logic; `app.js` wires them to the DOM. Crops are stored as normalised corner quads on each image `PageItem` and applied at export by a pure-JS perspective warp, so only the detector needs OpenCV.js (loaded lazily in a Web Worker). Browser behaviour is verified with a small dependency-free headless-Chrome runner (`tools/ui-check.js`).

**Tech Stack:** Vanilla JS (no build step), OpenCV.js 4.10 (`@techstark/opencv-js`, detector only), `heic2any` 0.0.4 (HEIC fallback, lazy), pdf-lib, Node 22+ for tests, headless Chrome for UI checks.

**Spec:** `docs/superpowers/specs/2026-10-15-auto-crop-design.md`

## Evidence that shapes this plan (measured before writing it)

A throwaway prototype of the classical detector was run against the 41 ground-truth photos (`~/Documents/page_crop_ground_truth/ground_truth.json`, derived from the user's own raw photos and manual crops):

| Detector | Mean IoU | IoU >= 0.90 | IoU >= 0.95 |
|---|---|---|---|
| Full-frame quad (baseline) | 0.607 | 0/41 | 0/41 |
| Fixed 5% inset (baseline) | 0.707 | 0/41 | 0/41 |
| Fixed 10% inset (baseline, best fixed inset) | 0.744 | 0/41 | 0/41 |
| Fixed centred crop at the median ground-truth area (baseline) | 0.744 | 0/41 | 0/41 |
| Edge/contour quad (prototype v1, discarded) | 0.594 | 0/41 | 0/41 |
| **Brightness-mask region (shipped in Task 8)** | **0.686** | **0/41 (95% CI 0-9%)** | **0/41** |

With a confidence score based on rectangularity and frame-edge contact, **0 of 41** photos reach confidence 0.6, so none would be auto-cropped. The cause is visible in the overlays: the photos show a pile of sheets on a desk, and a classical method finds the whole pile, not the top sheet.

**By the spec's own yardstick the classical detector is not working on these photos:** it scores below a fixed centred crop (0.686 vs 0.744), i.e. it adds nothing over how this user frames a page. (The 10% inset and centred baselines were measured on the same 41 photos, so they describe this user's framing; they are observations, not tuned parameters, and the 41 photos stay a held-out test set for Phase 2.)

**Consequences, stated plainly so nobody is surprised at execution time:**

1. The spec's Phase 2 gate (at least 85% of pages at IoU >= 0.90) will report **NOT MET** in Task 8. That is the expected outcome, not a failure of the task. Task 8 records the numbers and does not tune the detector to chase the gate.
2. On this user's pile photos, Auto Crop will mark pages **needs review** and leave them uncropped; it will not crop them. The detector's guess is deliberately **not** kept as a suggestion for the editor, because it is no better than a plain inset (0.686 vs 0.744). Review pages open the editor on a 10% inset. A clean single sheet on a plain desk is auto-cropped (Task 8 tests this on synthetic frames).
3. The value delivered by this plan is: cross-device ingestion fixes (HEIC, EXIF rotation, large photos), the manual crop editor with perspective export, the PDF-only rule, and the benchmark harness. "On point" automatic top-sheet detection needs the Phase 2 model, which is a separate plan to be written from the benchmark output.

## Global Constraints

- Everything runs in the browser: no uploads, no server, no telemetry (core property in `AGENTS.md`).
- Auto Crop applies to image pages only. If every uploaded file is a PDF (or there are no pages), the Auto Crop button is not shown, and PDF pages never get a Crop button. In a mixed upload the button is shown and acts on image pages only.
- Quads are `[[x, y] x4]` in TL, TR, BR, BL order, normalised 0..1 relative to the image.
- The crop editor opens on the page's stored crop, or else a 10% inset quad (`[[0.1, 0.1], [0.9, 0.1], [0.9, 0.9], [0.1, 0.9]]`), the best fixed start measured on the 41 photos.
- Constants: `WORKING_MAX_EDGE = 2000` px; `MAX_EXPORT_PIXELS = 12000000`; `CONFIDENCE_THRESHOLD = 0.6`; Phase 2 gate is 85% of pages at IoU >= 0.90.
- Design system (`AGENTS.md`): warm alabaster surfaces and terracotta accent via the existing CSS variables, SVG icons only, no emojis, 4px-based spacing, existing radius ramp, `prefers-reduced-motion` honoured (a global rule already exists), visible `:focus-visible` rings.
- Git: conventional commits (`feat:`, `fix:`, `chore:`, `docs:`, `test:`), imperative subject under 72 characters, no AI attribution or `Co-authored-by` lines (`AGENTS.md` and the user's global rules). `CLAUDE.md` files are read-only. `AGENTS.md` is updated with every code change.
- The user's photos and `ground_truth.json` are personal: never commit them. The benchmark reads them from paths given on the command line.
- The OpenCV.js module object is "thenable": never `await` it or resolve a Promise with it directly (it never settles). Always wrap it: `resolve({ cv })`.
- Asset version query strings are bumped to `2.5.0` in Task 10.
- UI checks need Node 22+ (global `WebSocket`) and Chrome at `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome` (override with `CHROME`).

## Review Focus

Inputs and conditions the spec implies but the happy-path tasks would not exercise. Each has a test in the task that owns the code.

1. **A portrait camera photo (JPEG with EXIF orientation 6) must come out upright in the PDF**, not sideways. Pinned in Task 2 (`canEmbedOriginalDirectly` refuses the raw-bytes shortcut), Task 5 (ingestion reports upright dimensions) and Task 6 (exported page is portrait).
2. **A HEIC file that cannot be decoded** (corrupt, or the decoder fails to load) must show an error toast and add no page, not hang or add a blank page. Pinned in Task 5.
3. **A very large photo (for example 6000 x 8000)** must export without exceeding the canvas pixel cap, and a failed canvas allocation must produce a readable error. Pinned in Task 1 (`capPixels`) and Task 6.
4. **Degenerate crops**: corners dragged to cross, collapse or leave the image must be clamped or rejected (Apply disabled with a message), and an invalid stored quad must be ignored at export instead of producing a garbage page. Pinned in Tasks 1, 6 and 7.
5. **Auto Crop edge cases**: PDF-only and empty uploads hide the button; manual crops are never overwritten; a detector or OpenCV load failure must say so (not silently mark every page "needs review"); running it twice is idempotent. Pinned in Tasks 3 and 9.

```js
/**
 * PDF Page Studio - Crop geometry helpers
 * Pure quad math and a perspective warp. Quads are four [x, y] points in
 * TL, TR, BR, BL order. Detection and the editor use normalised (0..1)
 * coordinates; the warp takes pixel coordinates.
 */
(function (root, factory) {
  if (typeof module === 'object' && module.exports) {
    module.exports = factory();
  } else {
    root.CropGeometry = factory();
  }
}(typeof self !== 'undefined' ? self : this, function () {

  const FULL_QUAD = [[0, 0], [1, 0], [1, 1], [0, 1]];

  function fullQuad() {
    return FULL_QUAD.map(p => p.slice());
  }

  /** Order four points as TL, TR, BR, BL. */
  function orderQuad(points) {
    const sums = points.map(([x, y]) => x + y);
    const diffs = points.map(([x, y]) => y - x);
    return [
      points[sums.indexOf(Math.min(...sums))],
      points[diffs.indexOf(Math.min(...diffs))],
      points[sums.indexOf(Math.max(...sums))],
      points[diffs.indexOf(Math.max(...diffs))]
    ];
  }

  /** Signed polygon area (positive when counter-clockwise in a y-up frame). */
  function polygonArea(poly) {
    let a = 0;
    for (let i = 0; i < poly.length; i++) {
      const [x1, y1] = poly[i];
      const [x2, y2] = poly[(i + 1) % poly.length];
      a += x1 * y2 - x2 * y1;
    }
    return a / 2;
  }

  function counterClockwise(poly) {
    return polygonArea(poly) < 0 ? poly.slice().reverse() : poly;
  }

  /** Sutherland-Hodgman clip of one convex polygon by another. */
  function clipConvex(subject, clipper) {
    let output = counterClockwise(subject);
    const clip = counterClockwise(clipper);
    for (let i = 0; i < clip.length; i++) {
      const a = clip[i];
      const b = clip[(i + 1) % clip.length];
      const input = output;
      output = [];
      const inside = (p) => (b[0] - a[0]) * (p[1] - a[1]) - (b[1] - a[1]) * (p[0] - a[0]) >= 0;
      const cross = (p, q) => {
        const a1 = q[1] - p[1], b1 = p[0] - q[0], c1 = a1 * p[0] + b1 * p[1];
        const a2 = b[1] - a[1], b2 = a[0] - b[0], c2 = a2 * a[0] + b2 * a[1];
        const det = a1 * b2 - a2 * b1;
        return [(b2 * c1 - b1 * c2) / det, (a1 * c2 - a2 * c1) / det];
      };
      for (let j = 0; j < input.length; j++) {
        const p = input[j];
        const q = input[(j + 1) % input.length];
        if (inside(q)) {
          if (!inside(p)) output.push(cross(p, q));
          output.push(q);
        } else if (inside(p)) {
          output.push(cross(p, q));
        }
      }
      if (output.length === 0) return [];
    }
    return output;
  }

  /** Intersection over union of two convex quads. */
  function quadIoU(a, b) {
    const inter = Math.abs(polygonArea(clipConvex(a, b)));
    const union = Math.abs(polygonArea(a)) + Math.abs(polygonArea(b)) - inter;
    return union > 0 ? inter / union : 0;
  }

  /** True when the quad is finite, convex, and covers at least minArea of the unit square. */
  function isValidQuad(quad, minArea) {
    if (!Array.isArray(quad) || quad.length !== 4) return false;
    if (!quad.every(p => Array.isArray(p) && p.length === 2 && Number.isFinite(p[0]) && Number.isFinite(p[1]))) return false;
    let sign = 0;
    for (let i = 0; i < 4; i++) {
      const [x1, y1] = quad[i];
      const [x2, y2] = quad[(i + 1) % 4];
      const [x3, y3] = quad[(i + 2) % 4];
      const cross = (x2 - x1) * (y3 - y2) - (y2 - y1) * (x3 - x2);
      if (cross === 0) return false;
      const s = cross > 0 ? 1 : -1;
      if (sign === 0) sign = s;
      else if (s !== sign) return false;
    }
    return Math.abs(polygonArea(quad)) >= (minArea === undefined ? 0.02 : minArea);
  }

  function clamp01(v) {
    return Math.min(1, Math.max(0, v));
  }

  function clampQuad(quad) {
    return quad.map(([x, y]) => [clamp01(x), clamp01(y)]);
  }

  /** Output rectangle for a quad in pixel space: mean of opposite edge lengths. */
  function quadOutputSize(quadPx) {
    const d = (p, q) => Math.hypot(p[0] - q[0], p[1] - q[1]);
    const [tl, tr, br, bl] = quadPx;
    return {
      width: Math.max(1, Math.round((d(tl, tr) + d(bl, br)) / 2)),
      height: Math.max(1, Math.round((d(tl, bl) + d(tr, br)) / 2))
    };
  }

  /** Scale (width, height) down, never up, so that width * height <= maxPixels. */
  function capPixels(width, height, maxPixels) {
    const pixels = width * height;
    if (pixels <= maxPixels) return { width, height, scale: 1 };
    const scale = Math.sqrt(maxPixels / pixels);
    return {
      width: Math.max(1, Math.floor(width * scale)),
      height: Math.max(1, Math.floor(height * scale)),
      scale
    };
  }

  /** Solve the 3x3 homography H (h33 = 1) that maps each src[i] to dst[i]. */
  function solveHomography(src, dst) {
    const A = [];
    const b = [];
    for (let i = 0; i < 4; i++) {
      const [x, y] = src[i];
      const [u, v] = dst[i];
      A.push([x, y, 1, 0, 0, 0, -u * x, -u * y]); b.push(u);
      A.push([0, 0, 0, x, y, 1, -v * x, -v * y]); b.push(v);
    }
    const n = 8;
    for (let col = 0; col < n; col++) {
      let pivot = col;
      for (let r = col + 1; r < n; r++) if (Math.abs(A[r][col]) > Math.abs(A[pivot][col])) pivot = r;
      if (Math.abs(A[pivot][col]) < 1e-12) throw new Error('Degenerate quad');
      [A[col], A[pivot]] = [A[pivot], A[col]];
      [b[col], b[pivot]] = [b[pivot], b[col]];
      for (let r = col + 1; r < n; r++) {
        const f = A[r][col] / A[col][col];
        for (let c = col; c < n; c++) A[r][c] -= f * A[col][c];
        b[r] -= f * b[col];
      }
    }
    const h = new Array(n);
    for (let r = n - 1; r >= 0; r--) {
      let s = b[r];
      for (let c = r + 1; c < n; c++) s -= A[r][c] * h[c];
      h[r] = s / A[r][r];
    }
    return [h[0], h[1], h[2], h[3], h[4], h[5], h[6], h[7], 1];
  }

  /**
   * Perspective-correct the quad (pixel coordinates in src) into an
   * outWidth x outHeight RGBA image using bilinear sampling.
   * src: { width, height, data: Uint8ClampedArray | Uint8Array (RGBA) }.
   */
  function warpPerspective(src, quadPx, outWidth, outHeight) {
    const rect = [[0, 0], [outWidth, 0], [outWidth, outHeight], [0, outHeight]];
    const H = solveHomography(rect, quadPx);
    const out = new Uint8ClampedArray(outWidth * outHeight * 4);
    const { width: sw, height: sh, data } = src;

    for (let y = 0; y < outHeight; y++) {
      for (let x = 0; x < outWidth; x++) {
        const px = x + 0.5, py = y + 0.5;
        const w = H[6] * px + H[7] * py + 1;
        const sx = (H[0] * px + H[1] * py + H[2]) / w - 0.5;
        const sy = (H[3] * px + H[4] * py + H[5]) / w - 0.5;
        const x0 = Math.max(0, Math.min(sw - 1, Math.floor(sx)));
        const y0 = Math.max(0, Math.min(sh - 1, Math.floor(sy)));
        const x1 = Math.min(sw - 1, x0 + 1);
        const y1 = Math.min(sh - 1, y0 + 1);
        const fx = Math.min(1, Math.max(0, sx - x0));
        const fy = Math.min(1, Math.max(0, sy - y0));
        const o = (y * outWidth + x) * 4;
        for (let c = 0; c < 4; c++) {
          const top = data[(y0 * sw + x0) * 4 + c] * (1 - fx) + data[(y0 * sw + x1) * 4 + c] * fx;
          const bottom = data[(y1 * sw + x0) * 4 + c] * (1 - fx) + data[(y1 * sw + x1) * 4 + c] * fx;
          out[o + c] = top * (1 - fy) + bottom * fy;
        }
      }
    }
    return { width: outWidth, height: outHeight, data: out };
  }

  return {
    fullQuad, orderQuad, polygonArea, quadIoU, isValidQuad, clampQuad,
    quadOutputSize, capPixels, solveHomography, warpPerspective
  };
}));
```

```js
/**
 * PDF Page Studio - Image ingestion helpers
 * Pure functions: EXIF orientation parsing, HEIC detection, working-copy
 * sizing, and the decision whether an original file can be embedded as-is.
 */
(function (root, factory) {
  if (typeof module === 'object' && module.exports) {
    module.exports = factory();
  } else {
    root.ImageNormalize = factory();
  }
}(typeof self !== 'undefined' ? self : this, function () {

  /**
   * Read the EXIF orientation (1-8) from JPEG bytes. Returns 1 when the
   * file is not a JPEG or carries no orientation tag.
   */
  function readJpegOrientation(input) {
    const bytes = input instanceof Uint8Array ? input : new Uint8Array(input);
    if (bytes.length < 4 || bytes[0] !== 0xFF || bytes[1] !== 0xD8) return 1;

    let offset = 2;
    while (offset + 4 <= bytes.length) {
      if (bytes[offset] !== 0xFF) return 1;
      const marker = bytes[offset + 1];
      if (marker === 0xDA || marker === 0xD9) return 1; // image data / end: no EXIF found
      const length = (bytes[offset + 2] << 8) | bytes[offset + 3];
      if (marker === 0xE1 && isExifHeader(bytes, offset + 4)) {
        return readOrientationFromTiff(bytes, offset + 10, offset + 2 + length);
      }
      offset += 2 + length;
    }
    return 1;
  }

  function isExifHeader(bytes, at) {
    return bytes[at] === 0x45 && bytes[at + 1] === 0x78 && bytes[at + 2] === 0x69 &&
      bytes[at + 3] === 0x66 && bytes[at + 4] === 0 && bytes[at + 5] === 0;
  }

  function readOrientationFromTiff(bytes, tiff, end) {
    if (tiff + 8 > end) return 1;
    const little = bytes[tiff] === 0x49 && bytes[tiff + 1] === 0x49;
    const big = bytes[tiff] === 0x4D && bytes[tiff + 1] === 0x4D;
    if (!little && !big) return 1;
    const u16 = (at) => little ? bytes[at] | (bytes[at + 1] << 8) : (bytes[at] << 8) | bytes[at + 1];
    const u32 = (at) => little
      ? (bytes[at] | (bytes[at + 1] << 8) | (bytes[at + 2] << 16) | (bytes[at + 3] << 24)) >>> 0
      : ((bytes[at] << 24) | (bytes[at + 1] << 16) | (bytes[at + 2] << 8) | bytes[at + 3]) >>> 0;

    const ifd = tiff + u32(tiff + 4);
    if (ifd + 2 > end) return 1;
    const count = u16(ifd);
    for (let i = 0; i < count; i++) {
      const entry = ifd + 2 + i * 12;
      if (entry + 12 > end) return 1;
      if (u16(entry) === 0x0112) {
        const value = u16(entry + 8);
        return value >= 1 && value <= 8 ? value : 1;
      }
    }
    return 1;
  }

  /** True for HEIC/HEIF files, by MIME type or extension (browsers often report an empty type). */
  function isHeicLike(file) {
    const type = (file.type || '').toLowerCase();
    if (type === 'image/heic' || type === 'image/heif' || type === 'image/heic-sequence' || type === 'image/heif-sequence') return true;
    return /\.(heic|heif)$/i.test(file.name || '');
  }

  /** Scale (width, height) so the long edge is at most maxEdge. Never upscales. */
  function fitWithin(width, height, maxEdge) {
    const longEdge = Math.max(width, height);
    if (longEdge <= maxEdge) return { width, height };
    const scale = maxEdge / longEdge;
    return { width: Math.max(1, Math.round(width * scale)), height: Math.max(1, Math.round(height * scale)) };
  }

  /**
   * Decide whether the original file bytes can go into the PDF untouched.
   * Returns 'png', 'jpg', or null (must be re-rendered through a canvas).
   * A JPEG with a non-default EXIF orientation must be re-rendered, because
   * PDF embedding ignores EXIF and would show it sideways.
   */
  function canEmbedOriginalDirectly(opts) {
    if (opts.hasCrop || opts.rotation !== 0 || opts.quality !== 1.0 || opts.enhanceScans) return null;
    const name = (opts.fileName || '').toLowerCase();
    if (name.endsWith('.png')) return 'png';
    if (name.endsWith('.jpg') || name.endsWith('.jpeg')) {
      return (opts.jpegOrientation || 1) === 1 ? 'jpg' : null;
    }
    return null;
  }

  return { readJpegOrientation, isHeicLike, fitWithin, canEmbedOriginalDirectly };
}));
```

```js
/**
 * PDF Page Studio - Crop state helpers
 * Pure rules for which pages Auto Crop applies to and how its results are
 * recorded on a page item.
 */
(function (root, factory) {
  if (typeof module === 'object' && module.exports) {
    module.exports = factory();
  } else {
    root.CropState = factory();
  }
}(typeof self !== 'undefined' ? self : this, function () {

  const CONFIDENCE_THRESHOLD = 0.6;

  /** Only photographed pages can be cropped; PDF pages never can. */
  function isCroppable(page) {
    return page.sourceType === 'image';
  }

  /** Number of image pages. The Auto Crop button is hidden when this is 0. */
  function countCroppable(pages) {
    return pages.filter(isCroppable).length;
  }

  /** Indexes Auto Crop should process: image pages the user has not cropped by hand. */
  function autoCropTargets(pages) {
    const targets = [];
    pages.forEach((page, index) => {
      if (isCroppable(page) && page.cropState !== 'manual') targets.push(index);
    });
    return targets;
  }

  /**
   * Record a detector result on a page. A confident result becomes the
   * crop. A weak one leaves the page uncropped and flags it for review.
   */
  function applyDetection(page, detection) {
    page.cropConfidence = detection.confidence;
    if (detection.quad && detection.confidence >= CONFIDENCE_THRESHOLD) {
      page.cropQuad = detection.quad;
      page.cropState = 'auto';
    } else {
      page.cropQuad = null;
      page.cropState = 'needs-review';
    }
    return page.cropState;
  }

  /** Record a quad confirmed in the crop editor. */
  function applyManualCrop(page, quad) {
    page.cropQuad = quad;
    page.cropState = 'manual';
    page.cropConfidence = 1;
  }

  /** Clear any crop on a page. */
  function resetCrop(page) {
    page.cropQuad = null;
    page.cropState = 'none';
    page.cropConfidence = 0;
  }

  /** Summarise states after a run: { cropped, review }. */
  function summarize(pages, indexes) {
    let cropped = 0, review = 0;
    indexes.forEach((i) => {
      if (pages[i].cropState === 'auto') cropped++;
      else if (pages[i].cropState === 'needs-review') review++;
    });
    return { cropped, review };
  }

  return { CONFIDENCE_THRESHOLD, isCroppable, countCroppable, autoCropTargets, applyDetection, applyManualCrop, resetCrop, summarize };
}));
```

```js
/** True when the page has a stored crop that is safe to apply. */
function hasUsableCrop(item) {
  return !!item.cropQuad && CropGeometry.isValidQuad(item.cropQuad);
}

/**
 * Render an image page to a canvas: orientation normalised, optional
 * perspective crop, then the user's rotation. Sizes are capped to
 * MAX_EXPORT_PIXELS so large phone photos stay within canvas limits.
 */
async function renderImagePageCanvas(item) {
  const { img, revoke } = await loadImageElement(item.fullBlob || item.sourceFile);
  try {
    const capped = CropGeometry.capPixels(img.naturalWidth, img.naturalHeight, MAX_EXPORT_PIXELS);
    let working = document.createElement('canvas');
    working.width = capped.width;
    working.height = capped.height;
    const workingCtx = working.getContext('2d', { willReadFrequently: true });
    if (!workingCtx) throw new Error('This photo is too large for this device to process.');
    workingCtx.drawImage(img, 0, 0, working.width, working.height);

    if (hasUsableCrop(item)) {
      const quadPx = item.cropQuad.map(([x, y]) => [x * working.width, y * working.height]);
      const natural = CropGeometry.quadOutputSize(quadPx);
      const size = CropGeometry.capPixels(natural.width, natural.height, MAX_EXPORT_PIXELS);
      const warped = CropGeometry.warpPerspective(
        workingCtx.getImageData(0, 0, working.width, working.height), quadPx, size.width, size.height
      );
      const cropped = document.createElement('canvas');
      cropped.width = warped.width;
      cropped.height = warped.height;
      cropped.getContext('2d').putImageData(new ImageData(warped.data, warped.width, warped.height), 0, 0);
      working = cropped;
    }

    const quarterTurn = item.rotation === 90 || item.rotation === 270;
    const out = document.createElement('canvas');
    out.width = quarterTurn ? working.height : working.width;
    out.height = quarterTurn ? working.width : working.height;
    const ctx = out.getContext('2d');
    ctx.translate(out.width / 2, out.height / 2);
    ctx.rotate((item.rotation * Math.PI) / 180);
    ctx.drawImage(working, -working.width / 2, -working.height / 2);
    return out;
  } finally {
    revoke();
  }
}

/**
 * Re-render an image page through a canvas (crop, rotation, scan enhance)
 * and embed it into the PDF.
 */
async function embedCanvasImage(mergedPdf, item) {
  const canvas = await renderImagePageCanvas(item);
  const ctx = canvas.getContext('2d');

  // USP 3: High-Contrast Document Scan Enhancer (B&W Photocopy Mode)
  if (state.settings.enhanceScans) {
    try {
      const imgData = ctx.getImageData(0, 0, canvas.width, canvas.height);
      const d = imgData.data;
      for (let p = 0; p < d.length; p += 4) {
        // Perceived luminance
        const lum = 0.299 * d[p] + 0.587 * d[p + 1] + 0.114 * d[p + 2];
        // S-curve contrast boost to wipe yellow lighting and background phone shadows
        const enhanced = lum > 175 ? 255 : (lum < 65 ? 0 : Math.round((lum - 65) * (255 / 110)));
        d[p] = enhanced;
        d[p + 1] = enhanced;
        d[p + 2] = enhanced;
      }
      ctx.putImageData(imgData, 0, 0);
    } catch (e) {
      console.warn('Scan enhance filter skipped:', e);
    }
  }

  const jpegQuality = state.settings.quality >= 1.0 ? 0.95 : state.settings.quality;
  const jpegBlob = await new Promise((resolve) => canvas.toBlob(resolve, 'image/jpeg', jpegQuality));
  if (jpegBlob) {
    try {
      return await mergedPdf.embedJpg(await jpegBlob.arrayBuffer());
    } catch (err) {
      // fall through to PNG
    }
  }
  const pngBlob = await new Promise((resolve) => canvas.toBlob(resolve, 'image/png'));
  if (!pngBlob) throw new Error('Could not encode this page. The photo may be too large for this device.');
  return mergedPdf.embedPng(await pngBlob.arrayBuffer());
}

/**
 * Produce the embedded image for an image page. The original bytes go in
 * untouched only when nothing needs to change (no crop, rotation, quality
 * change, enhance, or EXIF rotation); otherwise the page is re-rendered.
 */
async function embedImagePage(mergedPdf, item) {
  const direct = ImageNormalize.canEmbedOriginalDirectly({
    fileName: item.fileName,
    rotation: item.rotation,
    quality: state.settings.quality,
    enhanceScans: state.settings.enhanceScans,
    hasCrop: hasUsableCrop(item),
    jpegOrientation: item.jpegOrientation
  });

  if (direct) {
    try {
      const bytes = await item.sourceFile.arrayBuffer();
      return direct === 'png' ? await mergedPdf.embedPng(bytes) : await mergedPdf.embedJpg(bytes);
    } catch (err) {
      // fall through to the canvas path
    }
  }
  return embedCanvasImage(mergedPdf, item);
}
```

```js
/**
 * PDF Page Studio - Crop editor modal
 * Four draggable corners over the page image, with a magnifier loupe,
 * keyboard nudging, a focus trap and Escape to cancel. Validation uses
 * CropGeometry so the editor and the exporter agree on what a usable quad is.
 */
(function () {
  const INSET_QUAD = [[0.1, 0.1], [0.9, 0.1], [0.9, 0.9], [0.1, 0.9]]; // best fixed start measured on the 41 photos
  const CORNER_NAMES = ['top left', 'top right', 'bottom right', 'bottom left'];
  const DEFAULT_HINT = 'Drag the four corners onto the page edges. Arrow keys nudge a focused corner.';
  const INVALID_HINT = 'The corners cross or are too close together. Drag them back so they outline the page.';
  const LOUPE_SIZE = 112;
  const LOUPE_ZOOM = 3;
  const NUDGE = 0.005;
  const NUDGE_SHIFT = 0.02;

  let ui = null;      // cached elements, built on first open
  let session = null; // { quad, start, onApply, onRemove, dragging, opener }

  const copy = (quad) => quad.map((p) => p.slice());
  const clamp01 = (v) => Math.min(1, Math.max(0, v));

  function build() {
    if (ui) return ui;
    ui = {
      modal: document.getElementById('crop-modal'),
      backdrop: document.getElementById('crop-backdrop'),
      stage: document.getElementById('crop-stage'),
      image: document.getElementById('crop-image'),
      polygon: document.getElementById('crop-polygon'),
      loupe: document.getElementById('crop-loupe'),
      hint: document.getElementById('crop-hint'),
      apply: document.getElementById('crop-apply-btn'),
      cancel: document.getElementById('crop-cancel-btn'),
      close: document.getElementById('crop-close-btn'),
      reset: document.getElementById('crop-reset-btn'),
      remove: document.getElementById('crop-remove-btn'),
      handles: []
    };

    for (let i = 0; i < 4; i++) {
      const handle = document.createElement('button');
      handle.type = 'button';
      handle.className = 'crop-handle';
      handle.setAttribute('aria-label', `Crop corner: ${CORNER_NAMES[i]}`);
      ui.stage.appendChild(handle);
      ui.handles.push(handle);
      bindHandle(handle, i);
    }

    ui.apply.addEventListener('click', apply);
    ui.cancel.addEventListener('click', close);
    ui.close.addEventListener('click', close);
    ui.backdrop.addEventListener('click', close);
    ui.reset.addEventListener('click', () => {
      if (!session) return;
      session.quad = copy(session.start);
      render();
    });
    ui.remove.addEventListener('click', () => {
      const onRemove = session && session.onRemove;
      close();
      if (onRemove) onRemove();
    });
    ui.modal.addEventListener('keydown', onModalKeydown);
    return ui;
  }

  function pointFromEvent(e) {
    const rect = ui.stage.getBoundingClientRect();
    return [clamp01((e.clientX - rect.left) / rect.width), clamp01((e.clientY - rect.top) / rect.height)];
  }

  function bindHandle(handle, index) {
    handle.addEventListener('pointerdown', (e) => {
      if (!session) return;
      e.preventDefault();
      try { handle.setPointerCapture(e.pointerId); } catch (err) { /* synthetic or already-released pointer */ }
      session.dragging = index;
      handle.classList.add('dragging');
      moveTo(index, pointFromEvent(e));
    });
    handle.addEventListener('pointermove', (e) => {
      if (session && session.dragging === index) moveTo(index, pointFromEvent(e));
    });
    const end = () => {
      if (!session || session.dragging !== index) return;
      session.dragging = null;
      handle.classList.remove('dragging');
      ui.loupe.classList.remove('visible');
    };
    handle.addEventListener('pointerup', end);
    handle.addEventListener('pointercancel', end);
    handle.addEventListener('keydown', (e) => {
      const step = e.shiftKey ? NUDGE_SHIFT : NUDGE;
      const delta = { ArrowLeft: [-step, 0], ArrowRight: [step, 0], ArrowUp: [0, -step], ArrowDown: [0, step] }[e.key];
      if (!delta || !session) return;
      e.preventDefault();
      const [x, y] = session.quad[index];
      moveTo(index, [clamp01(x + delta[0]), clamp01(y + delta[1])], false);
    });
  }

  function moveTo(index, point, showLoupe = true) {
    session.quad[index] = point;
    render();
    if (showLoupe) drawLoupe(index);
  }

  function drawLoupe(index) {
    const img = ui.image;
    if (!img.naturalWidth) return;
    const [fx, fy] = session.quad[index];
    const displayWidth = img.clientWidth || img.naturalWidth;
    const source = (LOUPE_SIZE / LOUPE_ZOOM) * (img.naturalWidth / displayWidth);
    const ctx = ui.loupe.getContext('2d');
    ctx.clearRect(0, 0, LOUPE_SIZE, LOUPE_SIZE);
    ctx.drawImage(img, fx * img.naturalWidth - source / 2, fy * img.naturalHeight - source / 2, source, source, 0, 0, LOUPE_SIZE, LOUPE_SIZE);
    ctx.strokeStyle = 'rgba(194, 65, 12, 0.9)';
    ctx.lineWidth = 1;
    ctx.beginPath();
    ctx.moveTo(LOUPE_SIZE / 2, 0); ctx.lineTo(LOUPE_SIZE / 2, LOUPE_SIZE);
    ctx.moveTo(0, LOUPE_SIZE / 2); ctx.lineTo(LOUPE_SIZE, LOUPE_SIZE / 2);
    ctx.stroke();
    // Keep the loupe on the opposite side of the stage from the corner being dragged.
    ui.loupe.style.left = fx > 0.5 ? '8px' : `${Math.max(8, ui.stage.clientWidth - LOUPE_SIZE - 8)}px`;
    ui.loupe.classList.add('visible');
  }

  function render() {
    session.quad.forEach(([x, y], i) => {
      ui.handles[i].style.left = `${x * 100}%`;
      ui.handles[i].style.top = `${y * 100}%`;
    });
    ui.polygon.setAttribute('points', session.quad.map(([x, y]) => `${x * 100},${y * 100}`).join(' '));
    const valid = CropGeometry.isValidQuad(session.quad);
    ui.apply.disabled = !valid;
    ui.hint.textContent = valid ? DEFAULT_HINT : INVALID_HINT;
    ui.hint.classList.toggle('crop-hint-error', !valid);
  }

  function onModalKeydown(e) {
    if (e.key === 'Escape') {
      e.stopPropagation();
      close();
      return;
    }
    if (e.key !== 'Tab') return;
    const focusable = [...ui.modal.querySelectorAll('button:not([disabled])')].filter((el) => el.offsetParent !== null);
    if (focusable.length === 0) return;
    const first = focusable[0];
    const last = focusable[focusable.length - 1];
    if (e.shiftKey && document.activeElement === first) { e.preventDefault(); last.focus(); }
    else if (!e.shiftKey && document.activeElement === last) { e.preventDefault(); first.focus(); }
  }

  function apply() {
    if (!session || !CropGeometry.isValidQuad(session.quad)) return;
    const { quad, onApply } = session;
    close();
    if (onApply) onApply(copy(quad));
  }

  function close() {
    if (!ui || !session) return;
    const opener = session.opener;
    session = null;
    ui.modal.classList.remove('active');
    ui.loupe.classList.remove('visible');
    document.body.style.overflow = '';
    if (opener && typeof opener.focus === 'function') opener.focus();
  }

  /**
   * open({ imageUrl, quad, canRemove, onApply(quad), onRemove() })
   * Starts from `quad`, else a 10% inset.
   */
  function open(options) {
    build();
    const start = copy(options.quad || INSET_QUAD);
    session = { quad: copy(start), start, onApply: options.onApply, onRemove: options.onRemove, dragging: null, opener: document.activeElement };
    ui.remove.style.display = options.canRemove ? '' : 'none';
    ui.image.onload = () => render();
    ui.image.src = options.imageUrl;
    ui.modal.classList.add('active');
    document.body.style.overflow = 'hidden';
    render();
    ui.handles[0].focus();
  }

  window.CropEditor = { open, close, isOpen: () => !!session };
}());
```

Create `page-detect.js`:

```js
/**
 * PDF Page Studio - Page detector (classical, OpenCV.js)
 * Finds the main bright paper region in a photo and returns its four
 * corners as a normalised quad plus a confidence score. The OpenCV module
 * and the geometry helpers are injected so this runs in a Worker and in Node.
 *
 * Known limit: a pile of loose sheets is detected as one region, so the
 * top sheet is not isolated. Confidence is therefore low for those photos
 * (rectangularity is penalised for each frame edge the region touches).
 */
(function (root, factory) {
  if (typeof module === 'object' && module.exports) {
    module.exports = factory();
  } else {
    root.PageDetect = factory();
  }
}(typeof self !== 'undefined' ? self : this, function () {

  const WORK_EDGE = 640;          // longest side used for detection
  const MIN_REGION_AREA = 0.15;   // smallest accepted region, as a fraction of the frame
  const BORDER_MARGIN = 0.015;    // a region within this fraction of an edge "touches" it
  const BORDER_PENALTY = 0.3;     // confidence lost per touched frame edge

  function create(cv, geometry) {
    return function detect(frame) {
      const owned = [];
      const track = (mat) => { owned.push(mat); return mat; };
      const fallback = (note) => ({ quad: geometry.fullQuad(), confidence: 0, note });

      try {
        const scale = WORK_EDGE / Math.max(frame.width, frame.height);
        const src = track(cv.matFromImageData({ data: frame.data, width: frame.width, height: frame.height }));
        const small = track(new cv.Mat());
        cv.resize(src, small, new cv.Size(Math.round(frame.width * scale), Math.round(frame.height * scale)), 0, 0, cv.INTER_AREA);

        const rgb = track(new cv.Mat());
        const hsv = track(new cv.Mat());
        cv.cvtColor(small, rgb, cv.COLOR_RGBA2RGB);
        cv.cvtColor(rgb, hsv, cv.COLOR_RGB2HSV);
        const channels = new cv.MatVector();
        cv.split(hsv, channels);
        const sat = track(channels.get(1));
        const val = track(channels.get(2));
        channels.delete();

        // Paper is bright and unsaturated; the Otsu split adapts to the lighting.
        cv.GaussianBlur(val, val, new cv.Size(9, 9), 0);
        const mask = track(new cv.Mat());
        cv.threshold(val, mask, 0, 255, cv.THRESH_BINARY | cv.THRESH_OTSU);
        const unsaturated = track(new cv.Mat());
        cv.threshold(sat, unsaturated, 70, 255, cv.THRESH_BINARY_INV);
        cv.bitwise_and(mask, unsaturated, mask);
        const kernel = track(cv.getStructuringElement(cv.MORPH_ELLIPSE, new cv.Size(15, 15)));
        cv.morphologyEx(mask, mask, cv.MORPH_CLOSE, kernel);
        cv.morphologyEx(mask, mask, cv.MORPH_OPEN, kernel);

        const contours = new cv.MatVector();
        const hierarchy = track(new cv.Mat());
        cv.findContours(mask, contours, hierarchy, cv.RETR_EXTERNAL, cv.CHAIN_APPROX_SIMPLE);

        const W = small.cols, H = small.rows;
        let best = null;
        for (let i = 0; i < contours.size(); i++) {
          const contour = contours.get(i);
          const area = cv.contourArea(contour) / (W * H);
          if (area >= MIN_REGION_AREA && (!best || area > best.area)) {
            if (best) best.contour.delete();
            best = { area, contour };
          } else {
            contour.delete();
          }
        }
        contours.delete();
        if (!best) return fallback('no-region');
        track(best.contour);

        const hull = track(new cv.Mat());
        cv.convexHull(best.contour, hull);
        const approx = track(new cv.Mat());
        cv.approxPolyDP(hull, approx, 0.03 * cv.arcLength(hull, true), true);

        let points;
        if (approx.rows === 4) {
          points = [];
          for (let j = 0; j < 4; j++) points.push([approx.data32S[j * 2] / W, approx.data32S[j * 2 + 1] / H]);
        } else {
          points = cv.RotatedRect.points(cv.minAreaRect(hull)).map((p) => [p.x / W, p.y / H]);
        }
        const quad = geometry.orderQuad(geometry.clampQuad(points));

        const rect = cv.minAreaRect(best.contour);
        const rectArea = rect.size.width * rect.size.height;
        const rectangularity = rectArea > 0 ? Math.min(1, cv.contourArea(best.contour) / rectArea) : 0;
        const box = cv.boundingRect(best.contour);
        const touches =
          (box.x <= BORDER_MARGIN * W ? 1 : 0) +
          (box.y <= BORDER_MARGIN * H ? 1 : 0) +
          (box.x + box.width >= (1 - BORDER_MARGIN) * W ? 1 : 0) +
          (box.y + box.height >= (1 - BORDER_MARGIN) * H ? 1 : 0);
        const confidence = rectangularity * Math.max(0, 1 - BORDER_PENALTY * touches);

        if (!geometry.isValidQuad(quad)) return fallback('invalid-quad');
        return { quad, confidence, note: `rect=${rectangularity.toFixed(2)} touches=${touches}` };
      } catch (err) {
        return fallback('error: ' + (err && err.message ? err.message : err));
      } finally {
        owned.forEach((m) => { try { m.delete(); } catch (e) { /* already freed */ } });
      }
    };
  }

  return { create, WORK_EDGE, MIN_REGION_AREA, BORDER_MARGIN, BORDER_PENALTY };
}));
```

```js
 * Benchmark the page detector against the user's ground truth.
 * Usage: node bench_detector.js <ground_truth.json> <dir-of-working-copy-JPEGs> [--verbose]
 * Requires devDependencies (npm install): @techstark/opencv-js, jimp.

const path = require('path');
const Jimp = require('jimp');
const G = require('./crop-geometry.js');
const PageDetect = require('./page-detect.js');

function loadCv() { // the module object is thenable: never `await` it directly

    const cv = require('@techstark/opencv-js');
    if (cv.Mat) return resolve({ cv });
    cv.onRuntimeInitialized = () => resolve({ cv });
  });

function wilson(k, n, z = 1.96) {
  if (n === 0) return [0, 0];
  const p = k / n, d = 1 + z * z / n;
  const c = (p + z * z / (2 * n)) / d, h = (z * Math.sqrt(p * (1 - p) / n + z * z / (4 * n * n))) / d;
  return [Math.max(0, c - h), Math.min(1, c + h)];
}

(async () => {
  const [gtPath, dir] = process.argv.slice(2);
  if (!gtPath || !dir) { console.error('usage: node bench_detector.js <ground_truth.json> <jpeg-dir> [--verbose]'); process.exit(2); }
  const truth = JSON.parse(fs.readFileSync(gtPath, 'utf8'));
  const { cv } = await loadCv();
  const detect = PageDetect.create(cv, G);
  const rows = [];
  // Baseline (b): a fixed centred quad whose area is the median ground-truth area.
  const areas = truth.map((t) => Math.abs(G.polygonArea(t.quad_norm))).sort((a, b) => a - b);
  const side = Math.sqrt(areas[Math.floor(areas.length / 2)]);
  const centreQuad = [[0.5 - side / 2, 0.5 - side / 2], [0.5 + side / 2, 0.5 - side / 2], [0.5 + side / 2, 0.5 + side / 2], [0.5 - side / 2, 0.5 + side / 2]];
  for (const t of truth) {
    const img = await Jimp.read(path.join(dir, t.raw));
    const { width, height, data } = img.bitmap;
    const result = detect({ width, height, data });
    const diagonal = Math.hypot(width, height);
    const cornerError = result.quad.reduce((sum, p, i) => sum + Math.hypot((p[0] - t.quad_norm[i][0]) * width, (p[1] - t.quad_norm[i][1]) * height), 0) / 4 / diagonal;
    rows.push({
      raw: t.raw,
      iou: G.quadIoU(result.quad, t.quad_norm),
      fullFrame: G.quadIoU(G.fullQuad(), t.quad_norm),
      centre: G.quadIoU(centreQuad, t.quad_norm),
      cornerError,
      confidence: result.confidence,
      note: result.note
    });
  }
  const n = rows.length, mean = (xs) => xs.reduce((a, b) => a + b, 0) / xs.length;
  const sorted = rows.map((r) => r.iou).sort((a, b) => a - b);
  const share = (t) => rows.filter((r) => r.iou >= t).length;
  const [lo90, hi90] = wilson(share(0.9), n), [lo95, hi95] = wilson(share(0.95), n);
  const confident = rows.filter((r) => r.confidence >= 0.6);
  console.log(`pages: ${n}`);
  console.log(`mean IoU ${mean(sorted).toFixed(3)}  median ${sorted[Math.floor(n / 2)].toFixed(3)}`);
  console.log(`baselines (mean IoU): full-frame ${mean(rows.map((r) => r.fullFrame)).toFixed(3)}, centred median-area crop ${mean(rows.map((r) => r.centre)).toFixed(3)}`);
  console.log(`mean corner error ${(mean(rows.map((r) => r.cornerError)) * 100).toFixed(1)}% of the image diagonal`);
  console.log(`IoU >= 0.90: ${share(0.9)}/${n} (95% CI ${(lo90 * 100).toFixed(0)}-${(hi90 * 100).toFixed(0)}%)   IoU >= 0.95: ${share(0.95)}/${n} (95% CI ${(lo95 * 100).toFixed(0)}-${(hi95 * 100).toFixed(0)}%)`);
  console.log(`confident (>=0.6): ${confident.length}/${n}` + (confident.length ? `, their mean IoU ${mean(confident.map((r) => r.iou)).toFixed(3)}` : ''));
  const gateMet = share(0.9) / n >= 0.85;
  console.log(`Phase 2 gate (>=85% of pages at IoU >= 0.90): ${gateMet ? 'MET' : 'NOT MET -> start Phase 2 before promoting Auto Crop as reliable'}`);
  if (process.argv.includes('--verbose')) rows.sort((a, b) => a.iou - b.iou).forEach((r) => console.log(`${r.raw}  IoU ${r.iou.toFixed(3)}  conf ${r.confidence.toFixed(2)}  ${r.note}`));
  process.exit(0);
})();
```

Create `crop-worker.js`:

```js
/**
 * Crop detection worker. Loads OpenCV.js on the first job (about 10 MB, so
 * not at page load) and runs the page detector on one frame per message.
 *   in:  { id, width, height, buffer }   buffer = RGBA bytes (transferred)
 *   out: { id, quad, confidence, note }  or  { id, error }
 */
importScripts('crop-geometry.js', 'page-detect.js');

let cvPromise = null;

function loadCv() {
  if (!cvPromise) {
    cvPromise = new Promise((resolve) => {
      importScripts('vendor/opencv.js');
      // Resolve with a wrapper: the OpenCV module object is thenable, so
      // resolving a Promise with it directly would never settle.
      if (self.cv && self.cv.Mat) resolve({ cv: self.cv });
      else self.cv.onRuntimeInitialized = () => resolve({ cv: self.cv });
    });
  }
  return cvPromise;
}

self.onmessage = async (event) => {
  const { id, width, height, buffer } = event.data;
  try {
    const { cv } = await loadCv();
    const detect = PageDetect.create(cv, CropGeometry);
    const result = detect({ width, height, data: new Uint8ClampedArray(buffer) });
    self.postMessage({ id, quad: result.quad, confidence: result.confidence, note: result.note });
  } catch (err) {
    cvPromise = null; // allow a retry on the next job
    self.postMessage({ id, error: String((err && err.message) || err) });
  }
};
```

```js
/* ==========================================================================
   Auto Crop
   ========================================================================== */

let cropWorker = null;
let cropJobId = 0;
const cropJobs = new Map();

/** Show Auto Crop only when there is at least one photo (image page) to crop. */
function syncAutoCropButton() {
  const count = CropState.countCroppable(state.pages);
  elements.autoCropBtn.style.display = count > 0 ? '' : 'none';
  elements.autoCropLabel.textContent = `Auto Crop (${count})`;
}

function getCropWorker() {
  if (!cropWorker) {
    const worker = new Worker(`crop-worker.js?v=${ASSET_VERSION}`);
    worker.onmessage = (event) => {
      const job = cropJobs.get(event.data.id);
      if (!job) return;
      cropJobs.delete(event.data.id);
      if (event.data.error) job.reject(new Error(event.data.error));
      else job.resolve(event.data);
    };
    worker.onerror = (event) => {
      cropJobs.forEach((job) => job.reject(new Error(event.message || 'Crop worker failed')));
      cropJobs.clear();
      worker.terminate();
      if (cropWorker === worker) cropWorker = null;
    };
    cropWorker = worker;
  }
  return cropWorker;
}

/** Send one RGBA frame to the worker. The frame's buffer is transferred. */
function detectPage(frame) {
  return new Promise((resolve, reject) => {
    const id = ++cropJobId;
    cropJobs.set(id, { resolve, reject });
    try {
      getCropWorker().postMessage(
        { id, width: frame.width, height: frame.height, buffer: frame.data.buffer },
        [frame.data.buffer]
      );
    } catch (err) {
      cropJobs.delete(id);
      reject(err);
    }
  });
}

/** RGBA pixels of a page's working copy. */
async function getWorkingFrame(item) {
  const img = await loadImageFromUrl(item.thumbnailDataUrl);
  const canvas = document.createElement('canvas');
  canvas.width = img.naturalWidth;
  canvas.height = img.naturalHeight;
  const ctx = canvas.getContext('2d', { willReadFrequently: true });
  ctx.drawImage(img, 0, 0);
  return ctx.getImageData(0, 0, canvas.width, canvas.height);
}

async function runAutoCrop() {
  const targets = CropState.autoCropTargets(state.pages);
  if (targets.length === 0) {
    showToast('Nothing to crop: pages you cropped by hand are left alone.', 'error');
    return;
  }

  let failures = 0;
  showProcessingModal('Detecting Page Edges', 'Loading the detector...', 5);
  try {
    for (let n = 0; n < targets.length; n++) {
      const item = state.pages[targets[n]];
      updateProcessingProgress(`Checking ${item.fileName} (${n + 1} of ${targets.length})...`, 5 + Math.round(((n + 1) / targets.length) * 90));
      try {
        const result = await detectPage(await getWorkingFrame(item));
        const usable = CropGeometry.isValidQuad(result.quad);
        CropState.applyDetection(item, { quad: usable ? result.quad : null, confidence: usable ? result.confidence : 0 });
        await refreshCropPreview(item);
      } catch (err) {
        failures++;
        console.error('Auto crop failed for', item.fileName, err);
      }
    }
  } finally {
    hideProcessingModal();
  }

  renderPageGrid();

  if (failures === targets.length) {
    showToast('Auto Crop is unavailable right now. You can still crop each page by hand.', 'error');
    return;
  }
  const summary = CropState.summarize(state.pages, targets);
  const parts = [`${summary.cropped} cropped`];
  if (summary.review) parts.push(`${summary.review} need review`);
  if (failures) parts.push(`${failures} failed`);
  showToast(parts.join(', ') + '.', failures ? 'error' : 'success');
}
```

```markdown
- **Never use `await` on the OpenCV module object** (it is thenable); wrap it as `{ cv }`.
```
